\## How I Want to Work



When I ask you to do something that involves Python:



1\. \*\*Write or modify the script\*\* and save it to `/src`

2\. \*\*Tell me exactly how to run it\*\* — give me the cell to paste into my notebook and execute

3\. \*\*Don't edit my notebooks yourself\*\* — I'll copy what you give me and run it



This keeps me in control of what executes and helps me learn what each step does.

\## Pacing — This Is Important



\*\*Do one step at a time. Stop after each one and wait for me.\*\*



\- Don't bundle steps together

\- Don't anticipate what comes next

\- Each response should do one thing, explain it, then stop

\- If a task has multiple parts, ask me which to start with — don't start all of them



This is non-negotiable. The goal is understanding, not speed.
