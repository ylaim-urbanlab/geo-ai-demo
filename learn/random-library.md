# Random Library

`random` is a built-in Python module for generating random values.

A module is a file of reusable code you can import and use.

Why this matters here: `dice_roll()` uses `random.randint(1, 6)` to return a random die value from 1 to 6.

Example:

```python
import random

value = random.randint(1, 6)
print(value)
```
